# 免扫码连接（云端中转）

目标：**配置一次，以后手机出门直接连，不用再扫码**。

原理：你用的 Cloudflare 免费隧道网址每次重启都会变。我们在 Cloudflare 上放一个超小的「中转站」（Worker），
电脑每次拿到新网址就上报给它；手机打开 App 时先去中转站问「现在的网址是多少」，再连过去。
中转站**只存网址、不存 token**（token 一直在你手机本地），所以即使别人看到这个中转地址也连不上你电脑。

> 只需扫码 **一次**（带上中转地址），以后永久自动连。

---

## 一、建中转站（Cloudflare Worker，约 5 分钟，全免费）

1. 登录 https://dash.cloudflare.com → 左侧 **Workers & Pages**（在 Build → Compute 下）→ 右上角蓝色 **Create application**
   - 选模板 **「Start with Hello World!」**（不要选 Import a repository）
   - 起个名字（比如 `claude-rz`）→ **Deploy**（先把这个空的部署一下）。
2. 部署完 → **Continue to project**（或直接点进这个 Worker）→ 找 **Edit code**（有的版本叫 `</>` 或 **Quick edit**），
   把 [cloudflare-worker/rendezvous.js](../cloudflare-worker/rendezvous.js) 里的内容全选粘贴进去，覆盖原来的 Hello World 代码 → **Deploy**。
3. 建一个 KV 存储并绑定：
   - 左侧 **Storage & Databases → KV** → **Create a namespace**（名字随便，如 `rz-kv`）。
   - 回到 Worker → **Settings → Bindings → Add → KV namespace**：
     - Variable name 填 **`RZ`**（一定要叫 RZ）
     - KV namespace 选刚建的那个 → 保存。
4. 设一个发布密钥：
   - Worker → **Settings → Variables and Secrets → Add**：
     - 类型选 **Secret**，名字填 **`PUBLISH_SECRET`**，值自己随便编一串（比如 `change-me-to-a-random-string`）→ 保存。
5. 记下你的 Worker 网址，形如：`https://claude-rz.你的用户名.workers.dev`

## 二、电脑端填上中转信息

打开项目里的 `config.json`，把 `rendezvous` 改成你的：

```json
"rendezvous": {
  "url": "https://claude-rz.你的用户名.workers.dev",
  "secret": "change-me-to-a-random-string"
}
```

> `secret` 要和上面 Worker 里设的 `PUBLISH_SECRET` 一模一样。

保存后重启电脑端（关掉黑窗口重开 start.bat）。启动后控制台日志会出现
「已把当前网址上报到云端中转」，二维码也会自动带上中转地址。

## 三、手机扫一次

用手机扫电脑控制台上的新二维码（这次的码里带了中转地址）。扫这一次之后：
- 以后**隧道网址再怎么变，手机打开 App 都会自动找到当前网址连上**，不用再扫。
- 出门前忘了连也没关系——只要电脑开着、隧道起来了，手机点开 App 就连上了。

## 常见问题

- **中转站会泄露我的电脑吗？** 不会。它只存一个会过期的网址，不含 token。没有 token 谁也连不上。
- **手机一直连不上？** 确认电脑端在跑、`config.json` 的 url/secret 没填错；用手机浏览器直接打开你的
  Worker 网址，应能看到类似 `{"url":"https://...trycloudflare.com","at":...}`，说明上报成功。
- **想临时手动连？** App ⚙ 设置里仍可手填服务器地址 + Token。
- Cloudflare 免费额度对个人使用绰绰有余（每天 10 万次请求）。
